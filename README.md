# Provas Technologies

**Build Them Together.**

Provas Technologies is a technology-focused initiative dedicated to providing digital solutions and helping bridge the gap between students and companies.

## About the Project

This repository contains the source code for the official Provas Technologies website.

The website serves as an online presence for the company, showcasing its services, projects, and contact information.

## Technologies Used

- HTML5 – Website structure
- CSS3 – Styling and layout
- JavaScript – Interactive functionality
- Font Awesome 6.5.1 – Icons

## Website Sections

- Home
- About
- Services
- Projects
- Contact

## Features

- Navigation menu
- Services section
- Project showcase
- Contact section
- WhatsApp contact integration

## Project Structure

```text
provas-technologies/
├── index.html

└── images/
```

## Getting Started

1. Clone this repository:

   `git clone YOUR_REPOSITORY_URL`

2. Open the project folder.
3. Open `index.html` in your browser.
